# DiSpeechEval: Light-weight Speech Anaylsis
 Voice activity detection-based speech summarization and evaluation tool

 ## Quick Setup Guide
1. Have Python > 3.8 installed on your machine
2. Clone or download the repo to your computer
3. Install poetry: https://python-poetry.org/docs/#installing-with-the-official-installer
4. Open a terminal window in the dispeecheval directory and execute the command "poetry install"
5. To run DiSpeechEval, execute the command "poetry run python dispeecheval.py"
